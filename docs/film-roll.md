# 胶片组件技术栈与维护基线

记录日期：2026-10-04。运行时基线：`129bcc7`（收回动画修复）。本文记录网站的胶片组件，不是站外朋友圈九宫格制作流程。

## 1. 技术栈和入口

这是直接部署到 GitHub Pages 的静态组件：HTML + CSS + 原生 JavaScript，不使用 React、动画库、Canvas 或 WebGL。暗盒为透明像素 PNG；底片、齿孔和片头在浏览器中由 CSS 绘制，不是一张预先拼好的长图。照片使用独立 JPG。

| 文件 / 入口 | 职责 |
| --- | --- |
| `index.html` 的 `#film-list` | 摄影双螺旋下方的胶片列表容器；CSS、JS URL 带缓存版本 |
| `js/main.js` → `FILM_ROLLS` | 胶卷型号、双语名称、暗盒素材和照片顺序 / 原始编号 |
| `js/main.js` → `renderFilmRolls()` | 创建每卷 DOM；更新展开状态、提示文字、`aria-*`、`inert` |
| `js/main.js` → `initFilmScroll()` | 原生滚动、展开 / 收回定位、拖动、边缘拉伸和回弹、滚动条显示 |
| `css/style.css` 的“胶片”段落 | 横向布局、抽屉动画、单层底片与 SVG 遮罩、齿孔、手机尺寸 |
| `js/i18n.js` 的 `film.*` | 中英文提示文字；翻译变化会重新渲染列表 |
| `images/film/` | 两个统一比例的暗盒 PNG；`photos/5219/` 与 `photos/gold-200/` 存放网页照片副本 |
| `tests/film-roll.browser.cjs` | 开发用浏览器回归检查，不参与网站运行 |

使用的浏览器能力：CSS Grid / Flex、CSS 多层 mask（含 `-webkit-` 前缀）、CSS 自定义属性及 `@property`、`requestAnimationFrame`、`ResizeObserver`、Pointer Events / pointer capture、Wheel Events、`matchMedia`、`inert`。`prefers-reduced-motion: reduce` 下直接完成展开、收回与回弹。

暗盒 PNG 的原始生成方式记在 `images/film/README.md`；网站运行不需要图片生成服务。

## 2. DOM 与单层绘制原则

```text
.film-roll                        每卷一行，共用实现
├─ button.film-roll__canister     固定暗盒 + 型号 + 点击提示
└─ .film-roll__drawer             抽屉；唯一的展开 / 收回尺寸动画
   └─ .film-roll__clip            横向原生滚动和裁切窗口
      └─ .film-strip             唯一的棕色底片表面
         ├─ figure.film-strip__frame × N
         │  ├─ .film-strip__number
         │  └─ img
         └─ ::before / ::after   上、下两排齿孔
```

`.film-strip` 的棕色背景同时承载照片、片头和两排齿孔。片头没有独立 DOM、没有单独背景层：矩形主体遮罩与内嵌 SVG 片头遮罩共同裁切同一个元素，主体遮罩与片头重叠 **2px**，防止分数像素移动时露出发丝缝。

片头用短、平滑的曲线，不再用阶梯形像素剪口。原 SVG 视框 `40 × 112`，`preserveAspectRatio="none"` 随底片高度缩放；下侧有弧形缺口。上排齿孔延伸到片头上侧（距右缘仍保留12px），下排避开片头缺口。

不得新增常驻“垫底胶片”或独立齿孔层；否则拖动时会出现两条底片 / 两排重复齿孔。不得把片头拆成单独 span 再接到主体上。

## 3. 展开与收回：两种不同定位

以下 `W` 是未拉伸的底片宽度，`V` 是当前 `clip.clientWidth`，`M = max(0, W - V)`。实际代码用 `strip.getBoundingClientRect().width - pull` 得到 `W`，必须减掉左侧弹性拉伸造成的额外宽度。

### 展开

- 唯一的展开动画是抽屉 `grid-template-columns: 0fr → 1fr`。
- 展开期间每帧设置逻辑位置 `position = M`，再由 `paint()` 设置原生 `scrollLeft`。
- 片头相对窗口左缘的位置为 `W - scrollLeft = min(W, V)`，所以长卷片头到窗口右边缘就停，短卷则完整展示。照片多了不能继续把整卷往右送。
- 长卷首次展开展示靠近右侧片头的那一段，不是强制展示第一张；其它照片由展开后的自由横向浏览访问。
- 定位动画结束后必须放开滚动。用户开始横向滚轮、拖动、拖滚动条或导航键操作时会取消展开定位。

**禁止恢复** `.film-strip { transform: translateX(-100%) }` 的整卷位移动画。它曾与抽屉动画同时工作：底片越长，片头越容易跑出右侧窗口。

### 收回

收回不是展开公式的反向复用。先记录当前实际浏览位置 `from` 和收回前窗口宽度 `V0`，每帧执行：

```js
position = Math.min(M, from + Math.max(0, V0 - V));
```

这让正在看的那段胶片随窗口缩小连续移入暗盒。若用户此前看的是中间段，不能第一帧跳到 `M`，也不能先设置 `scrollLeft = 0`。

收完后裁切窗口为零；逻辑位置不一定在整卷末端，这不影响隐藏状态。下一次从完全关闭状态展开时再跟随真正片头。不要为了“收完必须滚到末端”增加一次可见跳转。

### 事件顺序、宽度与时长

- 暗盒先调用 `scroll.reset(true)`，**再**切换 `.is-open`。`reset()` 必须读取切换前的类名才能区分“将展开”与“将收回”。合并 / 调换两个监听器时必须保留此顺序。
- `ResizeObserver` 设置抽屉 `--film-length = W`，对应 `max-width`。短卷不能先收缩一段空白区域才开始收胶片；手机尺寸变化也要重测。
- 开关都保留 `overflow-x: auto` 与相同滚动条高度，不在关闭瞬间切成另一种滚动容器，避免布局抖动。隐藏靠 `0fr` 和 `inert`。
- CSS 抽屉动画 **900ms**，曲线 `cubic-bezier(0.22, 0.75, 0.25, 1)`；JS 定位跟随 **950ms**（覆盖动画末尾）。改变 CSS 时长必须同步 JS 跟随时长和测试等待时间。

## 4. 滚动、弹性和回弹

`position` 是可以越界的逻辑位置；`scrollLeft` 只能在 `[0, M]` 内。`paint()` 统一同步物理滚动与两个 CSS 变量。

- 向右拖最左端：`position < 0`，增大 `--film-pull`，作为**同一条底片的左侧 padding**。照片和齿孔向右，但底片仍从暗盒连接出来。不能整体向右平移并用第二层背景补洞。
- 向左拖最右端：`position > M`，使用 `--film-end-pull`，整条底片同向左移，片头仍属于这一表面。
- 阻力上限 `L = max(36, min(120, V × 0.25))`；可见拉伸 `L × (1 - exp(-越界距离 / L))`。逻辑位置防护范围为 `[-800, M + 800]`。
- Pointer 松手后立刻开始 **200ms** 回弹，按可见拉伸距离衰减，不按可能很大的累计手势距离衰减。
- 横向 wheel 事件在越界时立即回弹；`wheelEdge` 防止同一触控板手势的惯性反复重启回弹。**100ms 定时器只是清除手势边缘状态，不是回弹前的等待。**
- 普通纵向滚动、Ctrl 缩放不拦截；Shift + wheel 可横向浏览。`touch-action: pan-y` 保留手机纵向页面滚动。
- Pointer 位移达到 **6px** 才判定拖动；纵向优先的手势交给页面，窗口底部 **8px** 留给原生滚动条拖动。不要为改善胶片拖动而截获这些输入。
- `overscroll-behavior-x: none` 只关闭浏览器自己的第二套横向回弹，**不能删掉本组件的自定义弹性效果**。
- 不得为了修连接处断裂，把所有横向回弹直接禁用。

滚动时 `is-scrolling` 显示棕色滑块；停下 **900ms** 后清除此类，滑块再用 **650ms** 渐隐。显示过渡 **120ms**，滑块高度 **6px**。不要改成永远显示或完全不可浏览。

重新渲染前调用各卷 `cleanup()`，清理 RAF、定时器、pointer capture、事件监听与 `ResizeObserver`。中英文切换只保证保留展开 / 关闭状态，**当前实现不保存精确滚动位置**。

## 5. 视觉尺寸与数据维护

两卷均是 135 暗盒，应使用相同轮廓和画布位置。以 Gold 200 为模板，仅换标签；不得再次将 5219 画成更高瘦的另一种形状。

| 参数 | 桌面 | ≤480px |
| --- | --- | --- |
| 暗盒 PNG 显示尺寸 | 132 × 198px | 96 × 144px |
| 照片帧宽 / 高（3:2） | 108 / 72px | 78 / 52px |
| 底片上下 padding | 各20px | 各15px |
| 底片总高度 | 112px | 82px |
| 帧间距 | 18px | 12px |
| 左侧基础空白 | 32px | 24px |
| 片头宽 / 右侧预留 | 40 / 56px | 32 / 44px |
| 抽屉左边距 / 下移 | -28 / 14px | -20 / 10px |

暗盒原图都是 1024 × 1536 RGBA PNG；使用 `image-rendering: pixelated`。照片边框 3px，使用 `aspect-ratio: 3 / 2`、`object-fit: cover`。底片 `#34251f`，照片边框 `#1c1512`，编号 `#d5b887`；齿孔颜色跟随主题 `--c-paper`。

`FILM_ROLLS` 每项包含 `id`、双语 `name`、`stock`、`sprite` 和 `photos`，不为两个型号写两套交互代码。当前网站：5219 共9张；Gold 200 共12张。照片帧数不应硬编码进动画。

添加照片只需：

1. 将适合网页展示的 JPG 副本放进对应 `photos/5219/` 或 `photos/gold-200/`，原始扫描文件不变。
2. 副本文件名为六位原始编号，例如 `000068.jpg`。
3. 在 `FILM_ROLLS` 对应的编号数组中按希望显示的顺序加入 `68`。`src`、`alt`、`frame` 由 `.map()` 生成；照片顺序以数组为准，不自动排序。
4. 新型号沿用同一 DOM、暗盒尺寸和交互，仅添加数据项及素材。空 `photos` 显示三张未曝光占位帧和提示。

单独制作朋友圈九宫格时挑选的额外照片不等于网站已收录；不要把站外生成结果自动塞进仓库。

## 6. 已踩过的坑

| 错误改法 | 后果 / 正确替代 |
| --- | --- |
| 同时动画抽屉宽度和整卷 `translateX(-100%) → 0` | 长卷继续向右跑；只动画抽屉，展开跟随真实片头 |
| 为修展开而每帧强制 `scrollLeft = 0`（错误历史提交 `5004dc7`） | 两卷的片头都被推到屏幕外；展开应设 `M` |
| 收回也第一帧设 `M` | 浏览中间后先瞬间跳片头；用收回专属公式 |
| 独立拼接片头与底片 | 快速拖动出现细裂缝；同一背景 + 重叠遮罩 |
| 增加另一条常驻棕色底片 / 齿孔层 | 拉动时双层底片、重复齿孔；只保留 `.film-strip` |
| 回弹等待 wheel 停止，或用巨大累计距离插值 | 看起来先卡住再回弹；立即回弹并对可见距离缓动 |
| 抽屉比短卷还长 | 收回时先动画空白，看起来停顿；限制 `max-width` |
| 关闭时改变 overflow / 滚动条布局 | 可能突然改变垂直位置；滚动容器布局保持一致 |

## 7. 改动后如何验证

仅 `node --check js/main.js` 和 `git diff --check` 不足以验证动画。至少打开真实浏览器，检查两卷，并记录结果：

1. 首次展开：片头与右侧可视边缘贴合，停止后不继续移动；长卷不能按整卷长度展开到屏幕外。
2. 改成3张、12张、30张的临时测试数据：停点 / 时长不因张数变化；不改生产照片清单。
3. 横向浏览到中间 / 左端再收回：第一帧不得先跳到末端，内容连续向暗盒收回，无上下抖动。
4. 收完再重开：片头停点恢复正确；快速重复点击后最终类名、`aria-expanded`、`inert` 与可视状态一致。
5. 展开后两端拖拽与回弹：只存在一条底片与一套齿孔；暗盒连接处不露白，片头不产生细缝，松手即时回弹。
6. 1440px 桌面、390px 手机视口、宽屏、`prefers-reduced-motion`；普通纵向页面滚动仍可用。
7. 滑块滚动时出现，停止后渐隐；原生滑块和导航操作能够打断展开定位。
8. 改语言、窗口尺寸、重新渲染后无重复监听、残留拉伸或持续锁定滚动。

已用本机 Chromium 在桌面 / 手机模拟视口检查过主要展开、收回、滚动、回弹与快速切换的最终停点；**不是 iOS Safari / Android 实机认证**。快速切换的最终状态正确不等于“未收完又展开”的所有中间帧都已验证，涉及该场景时需另做逐帧检查。上面的完整清单也包含后续需要人工检查的视觉 / 输入项目，不应宣称全部已自动覆盖。

### 可重复运行的浏览器回归

```bash
node tests/film-roll.browser.cjs
```

开发环境需可用的 Playwright 和浏览器；网站本身仍零构建依赖。脚本使用本地 `index.html`，只在浏览器内临时修改测试照片数量，不写生产数据。若开发工具已经提供 Playwright / Chrome，可指定路径，不必给网站引入新的运行依赖：

```bash
FILM_PLAYWRIGHT_MODULE=/absolute/path/to/playwright \
FILM_BROWSER_EXECUTABLE=/absolute/path/to/chrome \
node tests/film-roll.browser.cjs
```

脚本覆盖展开停点、3 / 12 / 30张适配、左右滚动与回弹、中间位置收回轨迹、收回垂直位置、完全收回和快速切换的最终状态。肉眼检查接缝、齿孔、触控板手感和实机兼容性仍不可省略。

发布前更新 `index.html` 中对应 CSS / JS 的缓存查询参数；同步本文及测试，检查本任务文件后提交和推送。不要推送原始扫描照片、浏览器测试临时输出或站外制作成果。
